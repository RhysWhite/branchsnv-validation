# Supplementary Figures S1–S3 — Experiment 07

**Status:** manuscript review, not an amendment to any frozen scientific result or benchmark authorisation.

The figures and PNG previews are generated from the committed `figure_source_data.json`, the dated `POST_FREEZE_AUDIT_20261007.md`, and the October request-level reconciliation (`reconciliation_summary.json` and `request_level_reconciliation_5173.tsv`). The generator checks the complete 5,173-request classification and post-freeze 247→251 identity arithmetic before writing artwork. SVG labels, bars and geometry are programmatically generated, not manually edited.

Run at the root of the repository:

```bash
python3 manuscript/supplementary/experiment_07/make_figures.py
python3 manuscript/supplementary/experiment_07/make_figures.py --check
python3 manuscript/supplementary/experiment_07/verify_evidence.py
```

PNG generation requires CairoSVG, installed in the working environment. The SVGs remain editable as native text and shapes; regenerated files should match byte-for-byte. `--check` does not modify files.

# Pre-screening seed-tool recovery diagnostic

This directory records a search-sensitivity diagnostic performed before formal
eligibility screening or capability classification.

The diagnostic compared the frozen formal-search corpus with the 31-tool seed
registry that had been committed before formal database retrieval.

Name matching was deliberately conservative and generated candidate matches
for later human confirmation; it did not establish inclusion, relevance, or
benchmark eligibility.

Across the 14 prespecified direct, near-direct, and diagnostic-panel seed
comparators, 4 generated at least one candidate name match and 10 did not.
This 28.6% candidate-name recovery was considered insufficient for the formal
database search to stand alone as the software-landscape discovery mechanism.

The diagnostic therefore motivated the single generic high-recall expansion
described in Amendment 03. No inclusion/exclusion decisions or capability
classifications were made before that amendment.

# Pre-review triage operating-point acceptance criterion v1

## Frozen criterion

Select the smallest exact candidate review fraction whose minimum recall
across all nine held-out development batches is at least 0.95.

The criterion is declared after curve generation but before querying the
frozen curve for a qualifying point.

The intended use is high-recall pre-review prioritisation.

This criterion does not authorize automatic scientific exclusion, future
scoring, blind-validation content use, or production mutation.
